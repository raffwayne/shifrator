Справка по алгоритмам

  • Шифр Цезаря: Ключ — целое число (сдвиг). Например, 3.
  • Шифр Виженера: Ключ — слово из букв русского или английского алфавита.
  • Шифр Атбаш: Ключ не требуется (зеркальная подстановка алфавита).
  • Шифр Вернама: Ключ — строка, равная или длиннее текста (операция XOR).
  • Алгоритм RSA: Асимметричный алгоритм. Ключ — два простых числа через запятую (например, 11, 23).
  • Алгоритм DES: Симметричный блочный шифр. Ключ — строка (56 бит).

Юридическая информация:

Программа работает исключительно локально (Client-side processing). Данные не передаются по сети. Соответствует 152-ФЗ «О персональных данных». Предназначена только для учебных целей и не сертифицирована ФСБ России.
