## 📋 Описание

Кроссплатформенное веб-приложение для демонстрации и практического применения классических и современных алгоритмов шифрования текстовой информации. Все криптографические операции выполняются **исключительно локально** в среде веб-браузера (Client-side processing). Данные не передаются по сети.

### Поддерживаемые алгоритмы

1. **Шифр Цезаря** — классический шифр подстановки с числовым ключом
2. **Шифр Виженера** — многоалфавитный шифр с буквенным ключом
3. **Шифр Атбаш** — зеркальная подстановка (ключ не требуется)
5. **Шифр Вернама** — невзламываемый шифр с операцией XOR
6. **Алгоритм RSA** — асимметричное шифрование (учебная реализация)
7. **Алгоритм DES** — симметричный блочный шифр

## 🚀 Быстрый старт

### Способ 1: Локальный запуск (рекомендуется)

1. Распакуйте ZIP-архив в любую папку
2. Скачайте необходимые библиотеки (см. раздел «Библиотеки») в папку `libs/`
3. Откройте файл `index.html` в любом современном веб-браузере
4. Приложение готово к работе — интернет **не требуется**

### Способ 2: Развёртывание на веб-сервере

1. Загрузите все файлы на любой статический хостинг (GitHub Pages, Netlify и т.д.)
2. Перейдите по адресу развёрнутого сайта
